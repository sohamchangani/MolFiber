# MolFiber / MolRouter requirements.
#
# Install PyTDC with --no-deps. Its pins are the problem, not the package:
#
#   numpy<2.0.0,>=1.26.4   numpy 1.26.4 predates Python 3.13 and has no cp313
#                          wheel, so on 3.13 pip backtracks and tries to BUILD
#                          scikit-learn from source. That Cython build is what
#                          fails with "CompileError: sklearn/.../_cd_fast.pyx".
#
#   rdkit<2024.3.1         silently DOWNGRADES rdkit. Worse than a build error:
#                          Chem.CanonicalRankAtoms feeds GraphGrid's node-order
#                          tie-break and MurckoScaffoldSmiles feeds every
#                          scaffold split, so a downgrade can move results with
#                          no error message at all.
#
# It also drags in cellxgene-census, tiledbsoma, gget, transformers, datasets,
# accelerate and evaluate, none of which this pipeline touches. We use exactly
# two entry points -- tdc.single_pred.{ADME,Tox,HTS} and
# tdc.benchmark_group.admet_group -- and those need only numpy, pandas, requests,
# tqdm, fuzzywuzzy and pkg_resources (from setuptools).
#
#   python -m venv .venv && source .venv/bin/activate
#   pip install -r requirements.txt
#   pip install --no-deps PyTDC
#
# Python 3.11 or 3.12 is the smoother path; 3.13 works but more packages build
# from source.

# --- core ---
# Upper bounds are deliberate. Without them, --force-reinstall pulls the newest
# build of everything, and a C extension compiled against one numpy ABI loaded
# under another segfaults rather than raising. numpy 2.3+, pandas 3.x and
# transformers 5.x are all recent enough that much of the ecosystem is not built
# against them yet.
numpy>=1.26,<2.3
pandas>=2.0,<3.0
scikit-learn>=1.3,<1.8
rdkit>=2024.3
torch>=2.0,<3.0

# --- MolFormer view ---
# <5 matters: transformers 5.x is a major-version break and MoLFormer's Hub code
# is written against the 4.x API.
transformers>=4.51,<5.0

# --- OGB datasets (skip if only running --suite tdc) ---
ogb>=1.3.6
torch_geometric>=2.4,<3.0

# --- what PyTDC actually needs, installed here so --no-deps is safe ---
requests>=2.31
tqdm>=4.65
fuzzywuzzy>=0.18
setuptools<81          # tdc.metadata imports pkg_resources, removed in 81
openpyxl>=3.0
